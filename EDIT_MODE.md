# 📝 Edit Mode - Inline Editing Systém

## Aktivace Edit Mode

**Klávesová zkratka:** `Ctrl/Cmd + E`

Po aktivaci uvidíš v pravém horním rohu indikátor **"EDIT MODE"** se zeleným pozadím.

## Funkce

### 1. ✏️ Inline Text Editing

**Jak použít:**
- Klikni na libovolný text v prezentaci
- Text se změní na editovatelné pole
- Uprav text
- Stiskni `Enter` pro uložení nebo `Esc` pro zrušení
